# Changelog — kakao-food-card

## [0.2.0] - 2026-11-07
### Added
- 지역 검색 모드 `scan`: 검색어 여러 개로 후보 수집 → 동 단위 지역 필터 → 평점 관문
  - 평점 3.0 이상만 후보, 평점 비공개는 인기 맛집 태그·메뉴 랭킹 30위 이내·블로그 300건 이상 중 하나면 후보
  - 카페·디저트 기본 제외(`--cafe`), 패널 캐시로 재실행 시 새 가게만 수집
- 카드 판정 태그(제외 아님, 정보 표시)
  - 리뷰 의심: 리뷰 1~2개 계정 또는 평균 5.0 계정의 5점이 7일 안에 3건 이상, 툴팁에 기간·건수·보정 평균
  - 최근 하락: 최근 6개월 평균이 전체보다 0.5점 이상 낮음
  - 평점 비공개 / 리뷰 적음(10건 미만) / 최근 리뷰 없음 / 비싼 편(₩₩₩₩₩) / 체인점 / 예약 가능
- `blogs`: 블로그 후기 수집 + 네이버 본문으로 협찬 문구·체험단 배너·같은 날 몰림 판별 → 근거 후보
- `tag`: 저장된 원본으로 태그만 재계산
- 템플릿: 태그 칩(PC 호버·폰 탭 툴팁), 근거 태그(링크·인용), 요일 선택, 시간대별 방문자 막대(가장 붐빔·덜 붐빔), 평점 비공개 표시
### Changed
- `fetch`가 카카오 장소 ID도 받음, 최신 리뷰 3페이지(약 60건)까지 수집
- 평점 없는 가게도 정렬이 깨지지 않게 수정
- SKILL.md: 판정 기준 표, 지역 검색 모드·근거 고르기·게시 전 화면 확인 절차 추가

## [0.1.1] - 2026-11-06
### Fixed
- macOS·Windows 공통으로 동작하게 정비
  - 모든 파일 입출력을 UTF-8로 고정(Windows 기본 cp949에서 한글·이모지 깨짐 방지)
  - 표준출력도 UTF-8로 맞춰 리뷰 다이제스트 출력 오류 방지
  - `pick`을 macOS 전용 `sips` 대신 Pillow로 변환(EXIF 회전 반영), Pillow가 없는 macOS에서만 `sips`로 대체
  - `sheet`도 EXIF 회전을 반영, Pillow가 없으면 설치 안내 후 종료
- 가격 미기재 메뉴(`price: -1`)가 카드에 '-1원'으로 보이던 문제 수정
### Changed
- SKILL.md: 파이썬 실행기를 `$PY`(macOS `python3` / Windows `python`)로 표기, `pick`은 `-I` 없이 실행
