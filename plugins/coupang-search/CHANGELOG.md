# Changelog — coupang-search

## [0.2.0] - 2026-10-28
### Changed
- 상세 페이지 금지 해제 — 차단 원인은 페이지 종류가 아니라 타이밍(연달아 열기·동시 실행)이므로, 목록·상세 모두 같은 페이지 간격을 지키면 연다. 필요할 때만(치수·사양·리뷰 확인, 사용자가 준 링크) 연다.
- 상세 페이지 프롬프트 틀 추가(사양 원문·이미지 속 글자·리뷰 키워드 추출).
- `pacing.py log`: `--pages`(기존 `--searches` 호환)로 연 페이지 수, `--detail`로 그중 상세 수 기록. 출력 문구 '검색' → '페이지'.

## [0.1.0] - 2026-10-26
### Added
- 최초 버전: 검색 목록만 순차 조회하는 쿠팡 조사 스킬 + 간격 관리 스크립트 `pacing.py`(히스토리, 차단 시 1.5배 상향, 3연속 무차단 시 단축 제안, 최소 10초)
