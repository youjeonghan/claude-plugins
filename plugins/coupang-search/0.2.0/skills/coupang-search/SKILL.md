# coupang-search — 쿠팡 상품 조사

쿠팡은 짧은 시간에 페이지를 많이 열면 "요청하신 페이지의 사용권한이 없습니다 / 사용권한이 제한된 페이지입니다" 차단 페이지를 띄운다. 막힌 원인은 **페이지 종류가 아니라 타이밍**이다 — 페이지를 쉬지 않고 연달아 열거나 작업 두 개를 동시에 돌렸을 때 막혔고, 한 번에 하나씩 40초 간격으로 열었을 때는 15회 연속 막히지 않았다(2026-10). 상세 페이지도 같은 간격만 지키면 열어도 된다. 이 스킬은 그 방식을 고정하고, 페이지 간격을 기록으로 조정한다.

브라우저 작업은 Aside(`aside` CLI)로 한다. Aside가 없으면 같은 규칙으로 다른 브라우저 도구를 써도 되지만, 그 경우 히스토리 `--note`에 도구 이름을 적는다.

## 0. 간격 확인

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/coupang-search/scripts/pacing.py" status   # Windows는 python
```

- `간격`이 이번에 쓸 페이지 간 대기(초)다. 검색 목록·상세 페이지 모두 같은 간격을 적용한다.
- `단축 제안`이 있으면 사용자에게 알리고, 동의하면 `pacing.py set-interval <초>`로 바꾼다. 묻지 않고 바꾸지 않는다.
- 오늘 누적이 이미 많으면(예: 40회+) 사용자에게 알리고 진행 여부를 묻는다.

## 1. 규칙 (반드시)

- **페이지 사이 간격이 핵심이다.** 검색 목록이든 상세 페이지든, 페이지를 하나 연 뒤 다음 페이지를 열기 전에 **현재 간격(초) 이상** 기다린다.
- **동시 실행 금지.** Aside 세션 하나, 탭 하나. 다음 페이지는 같은 탭에서 주소만 바꾼다.
- 상세 페이지는 **필요할 때만** 연다 — 목록에 없는 치수·사양·리뷰 내용이 판단에 필요할 때, 또는 사용자가 상품 링크를 줬을 때. 가격·평점·리뷰 수·랭킹만 필요하면 목록으로 충분하다(목록 한 페이지에 72개가 있어 페이지 수가 훨씬 적다).
- 상세 페이지 안에서 리뷰 탭·더보기·스크롤은 같은 페이지 안 동작이라 새로 세지 않는다. 리뷰 다음 페이지를 여러 번 넘기는 건 각각 1회로 치고 간격을 둔다.
- 차단 문구가 보이면 **즉시 전부 멈춘다.** 재시도하지 않는다.
- 끝나면 연 탭을 닫는다. 로그인·구매·장바구니·글쓰기 금지.

검색 주소(쿠팡 랭킹순, 72개): `https://www.coupang.com/np/search?q=<검색어>&sorter=scoreDesc&listSize=72`
상세 주소: `https://www.coupang.com/vp/products/<상품번호>` (사용자가 준 링크면 `itemId`·`vendorItemId`까지 유지 — 옵션이 정해진다)

## 2. 실행

페이지를 **4개 안팎씩 묶어** 같은 세션을 이어 간다. 출력은 반드시 파일로 받는다(터미널 출력은 잘린다).

첫 묶음:

```bash
aside -m claude-code/claude-sonnet-5-5 --effort low "<프롬프트>" > <작업폴더>/b1.txt 2>&1
```

세션 ID는 출력 첫 줄(`created new session: <id>`)에 있다. 다음 묶음부터:

```bash
aside session resume <id> "<프롬프트>" > <작업폴더>/b2.txt 2>&1
```

### 검색 목록 프롬프트 틀 (`{interval}`·검색어만 바꾼다)

```
정보 추출 작업. 로그인·구매·장바구니·글쓰기 금지. 원문 그대로 항목별로만 반환, 요약·추천 금지.
규칙: 탭 하나만 쓰고 다음 페이지는 같은 탭에서 주소만 바꾼다.
페이지를 하나 연 뒤 다음 페이지를 열기 전에 최소 {interval}초 기다린다.
'사용권한이 없습니다', '사용권한이 제한된', 'Access Denied' 같은 차단 문구가 보이면 즉시 모든 작업을 멈추고 재시도하지 않는다.
끝나면 연 탭을 닫는다.
검색 주소: https://www.coupang.com/np/search?q=<검색어>&sorter=scoreDesc&listSize=72
검색어 순서대로: 1) … 2) … 3) … 4) …
각 검색마다 광고(AD) 상품은 건너뛰고 상위 10개: 순위. 상품명 | 판매가(할인이면 원가 → 할인율 → 판매가) | 평점 | 리뷰 수 | URL(coupang.com/vp/products/숫자 까지).
맨 끝에 반드시 아래 세 줄을 적는다:
연 페이지 수: <차단된 것 포함>
실제 대기: <페이지 사이 실제로 기다린 초>
차단됨: 없음  (막혔으면 → 차단됨: <몇 번째 페이지> <주소>, 첫 페이지 후 <경과 분>분)
```

### 상세 페이지 프롬프트 틀 (`{interval}`·주소·확인 항목만 바꾼다)

```
정보 추출 작업. 로그인·구매·장바구니·글쓰기 금지. 원문 그대로 항목별로만 반환, 요약·추천 금지.
규칙: 탭 하나만 쓰고 다음 페이지는 같은 탭에서 주소만 바꾼다.
페이지를 하나 연 뒤 다음 페이지를 열기 전에 최소 {interval}초 기다린다(같은 페이지 안 탭 전환·스크롤·더보기는 괜찮다).
'사용권한이 없습니다', '사용권한이 제한된', 'Access Denied' 같은 차단 문구가 보이면 즉시 모든 작업을 멈추고 재시도하지 않는다.
끝나면 연 탭을 닫는다.
상품 주소 순서대로: 1) … 2) …
각 상품마다: 상품명 | 선택된 옵션 | 판매가(원가 → 할인율 → 판매가) | 평점 | 리뷰 수 |
상세정보·상품정보 제공고시·옵션표에서 <확인 항목: 예) 크기(가로×세로×높이), 바닥 크기, 기둥 지름, 내하중, 무게, 재질> 원문 그대로(이미지로만 있으면 이미지 속 글자를 읽어 적고 '이미지에서 읽음' 표시, 없으면 '없음') |
리뷰에서 <키워드: 예) 흔들림, 대형묘> 언급 원문 최대 5개(별점 포함).
맨 끝에 반드시 아래 세 줄을 적는다:
연 페이지 수: <차단된 것 포함>
실제 대기: <페이지 사이 실제로 기다린 초, 1개면 0>
차단됨: 없음  (막혔으면 → 차단됨: <몇 번째 페이지> <주소>, 첫 페이지 후 <경과 분>분)
```

결과가 잘렸으면 **페이지를 다시 열지 말고** `aside session resume <id> "페이지 새로 열지 말고 N번 결과만 다시 출력해줘"`로 받는다.

## 3. 묶음마다 확인

결과 파일 끝의 `차단됨:` 줄을 본다.

**막혔을 때** — 남은 묶음은 진행하지 않는다.

```bash
python3 ".../pacing.py" log --pages <이번 작업에서 연 페이지 수, 막힌 것 포함> --detail <그중 상세 페이지 수> --actual <실제 대기> --blocked-at <작업 전체 기준 순번> --elapsed-min <경과 분> --note "<주제>"
```

사용자에게 그대로 보고한다:
- 막힌 시점의 간격(설정 X초, 실제 Y초), 작업 전체에서 몇 번째 페이지(목록/상세), 첫 페이지 후 경과, 오늘 누적
- 스크립트가 올린 다음 간격(1.5배)
- 그때까지 받은 결과는 쓰고, 남은 페이지는 몇 시간 뒤(최소 1~2시간)에 다시 하자고 제안. 막힌 상태에서 다시 열면 차단이 길어질 수 있다.

**끝까지 안 막혔을 때**:

```bash
python3 ".../pacing.py" log --pages <총 페이지 수> --detail <그중 상세 페이지 수> --actual <실제 대기> --note "<주제>"
```

출력에 `단축 제안`이 나오면 사용자에게 제안한다(같은 간격으로 3번 연속, 각 10회 이상 무차단일 때만 나온다. 최소 10초).

## 4. 고르기

- 기준: 쿠팡 랭킹순(광고 제외) + 리뷰 수. 같은 상품 번호의 색상·옵션 중복은 하나로 친다.
- 평점 3.5 이하, 리뷰 수 표시 없음은 대안이 없을 때만 넣고 단점에 적는다.
- 품목마다 고르는 기준(크기·재질 등)이 있으면 그것을 먼저 거른다. 목록에 없는 치수·사양은 후보를 좁힌 뒤 상위 몇 개만 상세 페이지로 확인한다. 확인하지 못한 값은 "미확인"으로 적고 지어내지 않는다.
- 결과 표: 순위 | 제품(링크) | `쿠팡 <가격> · 리뷰 <수>` | 장점 | 단점. 가격은 조사 날짜와 함께 적는다(로그인 안 한 가격이라 쿠폰·와우 할인 미반영).

## 히스토리

`~/.claude/coupang-search/`에 기기별로 쌓인다(플러그인 업데이트로 지워지지 않는다).
- `state.json`: 현재 간격, 마지막 변경 시각
- `history.jsonl`: 실행마다 한 줄 — 시각, 기기, 설정·실제 간격, 페이지 수(그중 상세 수), 오늘 누적, 차단 순번·경과, 메모
- 보기: `pacing.py history -n 20`
