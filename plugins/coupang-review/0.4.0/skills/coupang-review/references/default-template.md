# 기본 후기 템플릿 (2026-11-27 사용자 검증)

사용자 템플릿 파일이 없을 때 이 형식을 쓴다.
올리는 기기에 따라 **모드 두 개**가 있다. 기본은 **아이폰 모드**.

## 공통 규칙

- 글머리는 `- `만 쓴다(쿠팡 PC 웹이 `•`를 `&bull;`로 깨뜨림).
- 후기 본문에 `&`, 따옴표(`“ ” " ' ‘ ’`), 가운뎃점 `·`, `…`, `×`, `<` `>`, 줄표(`— –`), 출처 표시(￼)를 쓰지 않는다(`&amp;`, `&ldquo;` 등으로 깨짐).
  - 소제목 연결은 "와/과", 나열은 쉼표, 한 줄평은 따옴표 없이, 곱하기는 `x`.
- [사용 환경], [구매 이유]처럼 상품에 맞게 소제목은 바꾸거나 뺀다. 내용이 없는 섹션은 지운다.
- 상품 일반 정보 표시:
  - 크기, 두께, 재질, 색상, 구성품처럼 받아 보면 아는 정보는 표시 없이 평서문으로 쓴다.
  - "(상품 정보 기준)"은 사용자가 직접 확인하기 힘든 것(흡입력 같은 내부 수치, 인증, A/S 기간 등)에만, 한 후기에 되도록 1~2번만 붙인다.
  - 써 보면 저절로 아는 것(개봉 냄새, 포장, 조립, 무게감, 소음)을 상품 정보에서 옮겨 "~라고 해요"로 쓰지 않는다.
  - 설명서식 주의사항(열원 주의 등)은 옮기지 않는다.
- 성능, 사용 경험, 장점, 아쉬운 점, 한 줄평은 사용자가 말한 것만 쓴다.

## 모드별 차이

| 자리 | 아이폰 모드 (기본) | PC 모드 (윈도우 웹) |
|---|---|---|
| 제목 앞 | 없음 | 🚀 |
| 별점 | `별점: 5점 (5/5)` | `별점: 🚀🚀🚀🚀🚀 (5/5)` (점수만큼 🚀) |
| 가장 큰 장점 표시 | 문장 앞 `[가장 큰 장점]` | 문장 앞 ⭐ |
| 구분선 | `----------` | `⸻` |
| 한 줄평 제목 | `종합 한 줄평` | `✅ 종합 한 줄평` |

- 아이폰 앱에서 올리면 이모지(🚀 ✅)가 사라진다(2026-11-27 사용자 확인). 그래서 아이폰 모드는 이모지를 하나도 쓰지 않는다.
- 아이폰 앱에서 `&` 따옴표 등이 깨지는지는 아직 모른다. 공통 규칙대로 안 쓴다.
