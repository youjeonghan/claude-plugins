# Changelog — coupang-review

## [0.3.0] - 2026-11-27
### Added
- 사용자 템플릿(`~/.claude/coupang-review/template.md`)이 있으면 그 형식으로 출력.
- 상품 일반 정보(스펙·구성품·A/S·별도 구매 옵션)로 짧은 글을 채울 수 있게 함. 상품 페이지 원문 1순위 + "(상품 정보 기준)" 표시, 페이지에 없으면 리뷰 2개 이상 일치하는 사실만 바꿔 쓰고 미확인 알림.
- 상품 페이지 읽기 프롬프트에 스펙·구성품·A/S 추출 추가.
- 사용자 말과 상품 정보가 어긋나면 고치지 말고 묻기.
### Changed
- 0.2.1에서 뺀 Aside 모델 지정(`-m claude-code/claude-sonnet-5-5`) 복구. 모델을 못 쓰면 바꾸지 말고 사용자에게 Claude 연결을 요청.

## [0.2.1] - 2026-11-27
### Fixed
- Aside 호출에서 모델 지정(`-m claude-code/claude-sonnet-5-5`) 제거 — 계정에서 쓸 수 없는 모델이라 실행이 바로 실패함.

## [0.2.0] - 2026-11-27
### Changed
- 입력을 상품 링크 + 내 경험 + 사진으로, 출력을 복사용 텍스트(한줄 요약 + 상세리뷰)만으로 정리. 업로드·사진 첨부·별점은 사용자가 직접.
- 사진 촬영 목록은 기본 출력에서 빼고, 물을 때만 순서 제안.
- AI 글처럼 안 보이게: 사용자 단어·말버릇 유지, 소제목·목록·대칭 구조·상투어 금지 규칙 강화.
### Added
- 상품 페이지 1회 읽기(coupang-search 간격 규칙 공유): 상품명·옵션·다른 리뷰 최대 20개.
- 다른 리뷰에서 주제만 뽑아 내 경험에 빠진 포인트를 최대 4개 되묻기. 답한 것만 쓰고 남의 경험·문장은 옮기지 않음.

## [0.1.0] - 2026-11-27
### Added
- 최초 버전: 실사용 경험 인터뷰 → 상세리뷰·한줄 요약·별점·사진 촬영 목록 작성 스킬
- 쿠팡 체험단 선정 기준 조사 문서(`references/selection-research.md`, 공식 FAQ와 경험담 구분)
- 리뷰 활동·체험단 마감 기록 스크립트 `review_log.py`(status/add/invite/ordered/history)
