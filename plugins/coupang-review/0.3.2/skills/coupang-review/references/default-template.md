# 기본 후기 템플릿 (2026-11-27 사용자 검증: 쿠팡에 올려서 잘 나옴)

사용자 템플릿 파일이 없을 때 이 형식을 쓴다.
출처 표시(￼), 줄표(—)는 넣지 않는다.
별 이모지(⭐️·★) 대신 로켓(🚀)을 쓴다.
글머리는 `•` 대신 `- `를 쓴다(쿠팡 리뷰 칸이 •를 `&bull;`로 깨뜨림).
후기 본문에 `&`, 따옴표(`“ ” " ' ‘ ’`), 가운뎃점 `·`, `<` `>`를 쓰지 않는다(`&amp;`, `&ldquo;` 등으로 깨짐). 소제목은 "와/과", 나열은 쉼표, 한 줄평은 따옴표 없이.
별점 칸은 점수만큼 🚀를 반복한다(예: 4점 🚀🚀🚀🚀).

[사용 환경], [구매 이유]처럼 상품에 맞게 소제목은 바꿔도 된다.

```
🚀 <브랜드 모델명> 사용 후기

별점: 🚀🚀🚀🚀🚀 (5/5)
사용 기간: <사용자가 말한 기간>
구매 경로: 쿠팡

1. <구매 이유와 기본 스펙 / 첫인상과 기본 스펙>
- …

2. 성능과 사용 경험
- …

3. 구성품과 부가 기능
- …

4. 장점
- …

5. 아쉬운 점과 참고사항
- …

⸻

✅ 종합 한 줄평

…
```

- 기본 스펙·구성품·A/S 같은 상품 일반 정보는 상품 페이지 원문 기준으로 쓰고 "(상품 정보 기준)"을 붙인다.
- 성능·사용 경험·장점·아쉬운 점은 사용자가 말한 것만 쓴다.
